# An Empirical Analysis of Iterative Generation and Evaluation for Image Creativity

This repository contains the supplementary material for the following paper:

Yoshia Abe, Ryo Terajima, Tatsuya Daikoku, and Yasuo Kuniyoshi.  
"An Empirical Analysis of Iterative Generation and Evaluation for Image Creativity."  
In Proceedings of PRIMA 2026.  

## Contents

- supplementary.pdf: Detailed methods, additional analyses, prompts, list of themes, implementation details, and example outputs.
